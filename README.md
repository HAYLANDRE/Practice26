### 🛒 Корзина

#### Управление товарами:
1. **Просмотр товаров** — все добавленные часы
2. **Изменение количества** — кнопки + и − или введите число
3. **Удаление** — кнопка ✕ справа от товара
4. **Сумма** — автоматически считается сумма всех товаров

#### Оформление заказа:
1. Откройте **Корзину** (иконка 🛒)
2. Нажмите кнопку **"Оформить заказ"**
3. **Если не зарегистрированы:**
   - Появится окно регистрации
   - Заполните: Имя, Email, Телефон
   - **Валидация:** система проверит данные и покажет ошибки
   - Нажмите **"Зарегистрироваться"**
4. **Вернитесь в корзину** и снова нажмите "Оформить заказ"
5. Заполните форму:
   - **Адрес доставки** (улица, дом, квартира)
   - **Дата доставки** (выберите удобную дату)
6. Нажмите **"Подтвердить заказ"**
7. ✅ **Готово!** Вы получите подтверждение с деталями заказа

#### Стоимость доставки:
- **Бесплатно** по всей России!
- Доставка: **1-3 дня**

### 👤 Регистрация и профиль

#### Первая регистрация:
1. Нажмите **"Вход/Регистр."** в верхнем правом углу
2. Заполните форму:
   - **Ваше имя** (минимум 2 символа, максимум 50)
   - **Email** (должен быть в формате user@example.com)
   - **Номер телефона** (минимум 10 цифр)
3. **Валидация в реальном времени:**
   - При уходе из поля проверяется корректность
   - Ошибки показываются красным текстом под полем
   - Кнопка "Зарегистрироваться" активна только при всех корректных данных
4. Нажмите **"Зарегистрироваться"**

#### Ваш профиль:
- После регистрации ваше **имя отобразится в меню** (верхний правый угол)
- Нажмите на имя для выхода из аккаунта

#### Выход:
1. Нажмите на ваше имя в верхнем правом углу
2. Выберите **"Выход"**
3. Ваша корзина будет очищена (при следующем входе начнете с нуля)

## 🔧 РАЗРАБОТКА

### Технологический стек:
- **Vue 3** (Composition API)
- **Vite** (быстрая разработка)
- **CSS3** (модные стили)
- **JavaScript ES6+** (ванильный JS)

### Команды:

```bash
# Перейти в папку проекта
cd watch-shop

# Установить зависимости
npm install

# Запустить dev сервер (http://localhost:5174)
npm run dev

# Собрать для продакшена
npm run build

# Просмотр продакшен версии
npm run preview
```
